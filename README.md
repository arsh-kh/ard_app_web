# Ard Bazar

A Point of Sale (POS) and inventory management app built for bakeries and local shops.

## Features

- **Inventory Tracking:** Keep track of stock in bags, kg, tons, or boxes. Shows warnings when stock gets low.
- **Point of Sale:** Quickly add items to a cart, check out walk-in customers, or assign orders to specific clients.
- **Invoices:** Generate PDF invoices for individual orders, or create reports for specific date ranges (weekly, monthly, yearly).
- **Client Profiles:** See order history and track balances for each customer.
- **Languages:** Works natively in Kurdish, Arabic, and English.
- **Database:** Uses Firebase Firestore to keep data synced.

## Tech Stack
- Flutter (Mobile & Web)
- Firebase Firestore & Auth
- Riverpod for state management

## Platforms
Compiles to Android, iOS, and Web browsers.
